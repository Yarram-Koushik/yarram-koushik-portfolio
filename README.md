# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Yarram-Koushik/yarram-koushik-portfolio.git
```

Navigate to the project folder

```bash
cd yarram-koushik-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```

Create a production build

```bash
npm run build
```
